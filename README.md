
# Meus sites favoritos

## Sobre o projeto

Este projeto foi desenvolvido como atividade de HTML.

A página apresenta cinco sites favoritos, com seus nomes,
imagens e links para acesso.

## Sites favoritos

1. Stardew Valley Wiki
2. Wiki Naruto
3. YouTube
4. Canva

## Tecnologias utilizadas

- HTML
- CSS
- Visual Studio Code

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html em um navegador.
4. Clique nos links para acessar os sites favoritos.
